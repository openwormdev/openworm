02 / REPRODUCIBILITY

A connectome.
Not a financial oracle.

This laboratory uses c302’s C1 equations and its default historical connectivity reader. It does not recreate all of a living worm’s physiology. Synaptic parameters, financial inputs, and readout thresholds carry substantial modeling assumptions.

The brain is continuous within a replay, then reset for the next token experiment. The browser replays saved traces; it does not emulate c302. Zero trades are a valid result.
